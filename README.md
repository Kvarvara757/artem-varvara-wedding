# Свадебный сайт Артём & Варвара

## Что менять
Открой `config.js` — там находятся имена, дата, тексты, программа, адрес, карта, дресс-код и цвета.

## Как добавить фото
Замени блоки `.hero-bg` и `.place-photo` в `style.css` на свои фоновые изображения или попроси меня сделать это после того, как загрузишь фотографии.

## Ответы гостей
В `config.js` укажи `rsvpEmail: 'твояпочта@example.com'`. Тогда после заполнения анкеты у гостя откроется письмо с его ответом.

## Как держать сайт онлайн
Самый простой вариант — загрузить папку на GitHub Pages или Netlify. Файлы остаются у тебя, и ты можешь менять их в любой момент.
